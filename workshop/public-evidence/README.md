# Real public evidence examples

These files contain **real public bibliographic metadata**, retrieved separately
from the fictional workshop organization. Each JSON records source, query, date,
selection method and access status. They are source-discovery exercises, not
recommended studies or an exhaustive evidence review.

The three topic snapshots contain three deliberately selected, DOI/title-checked scientific teaching examples each. Check the actual
paper before attributing any result to it; metadata retrieval does not verify a
claim. Follow the linked license before obtaining or redistributing full text.
No abstracts or publisher full text are redistributed in these snapshots.

Use these for DOI lookup, author/title checks, study selection, source-quality
questions and discovery of real-disease evidence. Never cite them as evidence for
NORVANTIB, DERMALYX or ADIPOSYN. Those products are fictional.

Refresh deliberately with `python3 scripts/curate_public_examples.py`.
See [API setup](../../docs/api-setup.md) and the original service documentation.
