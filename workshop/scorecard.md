# Scorecard and awards

Five minutes per team. Five headings. Then everyone votes.

---

## What each team presents

**1. The job** — What did you give it?

**2. The skills** — What Medical Affairs expertise did you teach it in Round 2?
Read out one of your house rules.

**3. The work** — What did it do on its own that you did not tell it to do?

**4. The result** — Was it actually useful? Would you have sent it to anyone?

**5. The failure** — Where did it still need a human?

> **Point 5 is not optional.** A team with nothing to say there did not look
> hard enough. If they are stuck, ask the room to help them find it — someone
> always can.

---

## The awards

Everyone votes. One vote per person per award. Teams may not vote for
themselves.

### 🏆 Best Agent
Whose agent did the most genuinely useful work?

### 🧠 Best Medical Affairs Skill
Whose house rule best captured something an experienced person knows and a
generic agent does not? Judge the rule, not the output.

### ⚡ Biggest Time Saver
What would have taken longest by hand?

### 🤯 Most Surprising Result
What did an agent find that nobody expected — a buried contradiction, a signal
in the field notes, a question nobody had thought to ask?

### 🚨 Most Dangerous Agent Mistake

**Present this one last, and do not present it as a joke.**

What did an agent produce that was wrong in a way that would have mattered —
and that a busy person would plausibly have accepted?

Candidates: a fabricated citation, a promotional claim, an adverse event that
went unremarked, a cross-trial comparison presented as evidence, a confident
conclusion from a single-arm study.

The winner of this award has done the room the biggest favour. Say so.

---

## Judging the house rules

If you want a tiebreaker for **Best Medical Affairs Skill**, a good rule is:

| | |
|---|---|
| **Specific** | Names the actual behaviour, not a sentiment |
| **Explains why** | Gives the reason, so it generalises to cases nobody anticipated |
| **Changed the output** | The before/after is visibly different |
| **Would transfer** | Another company would recognise it as true |

The last criterion is worth pointing out: rules that pass it are exactly the
ones worth contributing back to the repository.

---

## After the voting

Two minutes, and then stop:

- Collect every team's `house-rules/` file.
- Collect every mistake found — especially the dangerous ones. Each is a
  GitHub issue worth filing.
- Ask who wants to keep going with this next week, and write those names down.

The output worth keeping is not the deliverables. It is the rules.
