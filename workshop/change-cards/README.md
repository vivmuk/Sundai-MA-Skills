# New information has arrived

SYNTHETIC DATA - facilitator-selected change exercises.

Give one card after the agent has produced its initial capstone. All changes are
fictional and affect only the selected exercise. Do not present them as real news.

| Card | Works with | What the team should request |
|---|---|---|
| [Budget cut](budget-cut.md) | All areas | Reprioritize and show deferred work |
| [Source correction](source-correction-oncology.md) | Oncology | Trace a changed result into every affected draft |
| [Advisor withdraws](advisor-withdraws.md) | Advisory-board missions | Reassess expertise coverage and questions |
| [Content expiry](content-expiry.md) | Connected planning | Identify stale assets and prevent their proposed distribution |

The desired behavior is evidence-based revision. Unchanged conclusions may remain
unchanged if the agent explains why. Do not require a dramatic reversal for show.
