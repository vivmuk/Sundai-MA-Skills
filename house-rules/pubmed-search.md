# House rules — `pubmed-search`

Rules here override the defaults in `skills/pubmed-search/SKILL.md`.
See [README.md](README.md) for how to write a good one.

## Seeded examples

- Always run the search on both the generic name and the development code. Our
  pivotal trials were published under the code and a generic-only search misses
  them entirely.
- Any literature review supporting an external deliverable must document the
  exact query string and date. Reviewers reject undocumented searches.
- Do not restrict to English unless you say so in the limitations. We have been
  caught out by Japanese and Chinese real-world data twice.
