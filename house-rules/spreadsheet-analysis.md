# House rules — `spreadsheet-analysis`

Rules here override the defaults in `skills/spreadsheet-analysis/SKILL.md`.
See [README.md](README.md) for how to write a good one.

## Seeded examples

- Always run `inspect` before any analysis and report the data-quality findings
  alongside the results. Our CRM exports have multi-row headers.
- Publish the category collapsing decisions with every count. A frequency that
  silently merges three concepts is not interpretable.
- Every tracker we produce carries a source column and an evidence-tier column.
  Reviewers reject trackers without them.
