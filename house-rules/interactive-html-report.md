# House rules — `interactive-html-report`

Rules here override the defaults in `skills/interactive-html-report/SKILL.md`.
See [README.md](README.md) for how to write a good one.

## Seeded examples

- HTML attachments are blocked by our email gateway. Print to PDF and send that,
  or host on `[internal location]` and send the link.
- Never put safety data behind a collapsed section. A reader who prints the page
  must still see it.
- All reports must work with JavaScript disabled — our locked-down desktops
  disable it by default.
