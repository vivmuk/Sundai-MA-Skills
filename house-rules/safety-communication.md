# House rules — `safety-communication`

Rules here override the defaults in `skills/safety-communication/SKILL.md`.
See [README.md](README.md) for how to write a good one.

## Seeded examples

- Nothing in a safety communication discharges a pharmacovigilance obligation. State this in every draft.
- Any safety communication is reviewed by Pharmacovigilance before it leaves Medical Affairs, without exception.
- Never characterise a signal as 'not a safety concern' before the assessment concludes. Describe what is known and what is being assessed.
- Label safety changes are communicated using the approved label wording, not a paraphrase.
