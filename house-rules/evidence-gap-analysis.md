# House rules — `evidence-gap-analysis`

Rules here override the defaults in `skills/evidence-gap-analysis/SKILL.md`.
See [README.md](README.md) for how to write a good one.

## Seeded examples

- Do not propose a study simply because data are missing. Explain why closing
  the gap changes a decision, and name the decision-maker.
- Check whether existing data already answer the question before proposing new
  research. A meaningful share of our "gaps" are unpublished analyses of data we
  already hold.
- Always present the below-the-line list. Leadership debates the trade-off, and
  a funded-only list hides it.
