# House rules — `field-medical-planning`

Rules here override the defaults in `skills/field-medical-planning/SKILL.md`.
See [README.md](README.md) for how to write a good one.

## Seeded examples

- Field prioritisation is built from scientific criteria. Commercial targeting data is not an input to the medical plan.
- MSL objectives describe what changes, not how many interactions occur. Interaction counts are operational, never a performance target.
- The plan must fit modelled capacity, including preparation, insight write-up and follow-up. State what falls below the line.
- No shared volume objectives with sales, and no message cascade to the field.
